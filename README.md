# WJ Client

An original Fabric client-side mod for Minecraft 26.2.

## Status

Early development. The current foundation focuses on a small module system and client lifecycle integration. The ClickGUI, HUD editor, configuration persistence, and additional modules are not implemented yet.

## Requirements

- Minecraft 26.2
- Java 25
- Fabric Loader 0.20.1
- Fabric API 0.161.0+26.2

## Build

Use Gradle 9.2 or a compatible version supported by Fabric Loom 1.19-SNAPSHOT:

```sh
gradle build
```

The output JAR is written to `build/libs/`.
